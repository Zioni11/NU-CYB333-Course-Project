# Local Cyber Range (Docker-Based)

This project is a localized cyber testbed environment built using Python and Docker.  

It allows you to simulate cyber attacks, test defensive tools, and experiment with vulnerable services in a safe, isolated environment.

## Features
- Python-based orchestrator for automated lab setup
- Attacker container (Kali Linux)
- Victim container (DVWA vulnerable web app)
- Custom Docker network for isolated attack simulation
- Optional attack modules (Nmap, brute force, SQLi tools)

## Requirements
- Docker Desktop or Docker Engine
- Python 3.x
- VS Code with Python extension
